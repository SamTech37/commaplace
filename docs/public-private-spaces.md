# Comma 閱覽與工作桌

2026-09-11，依互動原型確認的第一版。

- 首頁與「閱覽」開啟公開推薦內容。「工作桌」開啟私人的寫作與組織環境。
- 工作桌由左側文章列切換，目前文章與參照文章並排；不再提供文章分頁。
- 「我的空間」是一篇可以編輯的主文章，包含導言、文字段落、按作者安排順序的子文章。
- 主文章的公開入口為 `/{handle}`。尚未發布主文章的作者保留既有個人頁。
- 每篇子文章可設為公開或半公開。兩者都可閱讀、分享、搜尋與收藏；半公開不加入推薦與漫遊。追蹤列表與作者自己建立的連結仍可呈現半公開文章。
- 自動儲存只改動私人草稿。「更新／發布」才更新公開內容及搜尋、標籤、連結索引。
- 從主文章調整子文章公開設定，只改變曝光範圍，不會發布該篇尚未完成的文字修改。
- 主文章包含草稿時，發布前必須明確勾選要一起發布的草稿。未勾選的草稿保留在工作桌，不出現在公開主文章。
- 主文章使用修訂版本避免多個編輯器互相覆蓋。既有文章 API 同樣在儲存及發布時檢查版本。

既有工作桌的狀態資料保留在資料庫，新的介面不載入舊式分頁與畫布。
